# App Store assets + P0 scope

## Working Duo screenshot sizes

- Outer display: **1398 × 2034** portrait / **2034 × 1398** landscape
- Inner display: **2853 × 2007**

Validate again in App Store Connect before final upload.

## Screenshot story

1. Two secret sides
2. Fold = reveal
3. Catch both reactions
4. Ready for short-form vertical sharing
5. Made for Duo

Do not lead with settings, permissions, feature grids or API names.

## P0 not-to-do

Until export/share behavior is proven, do not build:

- accounts
- followers/friends
- feed
- messaging
- cloud sync
- creator marketplace
- AI prompt generation
- complex editor timeline
- Android
- full ordinary-iPhone parity
- subscription paywall
- UGC moderation backend
- more than one export template

When a feature competes with reliable capture, physical reveal, one-tap export or prompt quality, the feature loses.
